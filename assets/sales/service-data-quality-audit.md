# 服務介紹：資料健檢（Data Quality Audit）

> 你的報表數字對不對？我幫你查清楚，給你一份老闆看得懂的健檢報告。

---

## 你現在的痛點

- 報表出來的數字「感覺怪怪的」，但不知道哪裡出問題
- 不同表格的同一個數字對不起來
- 月底對帳發現錯誤，但已經太晚了
- 老闆問「這個數字準嗎」，你沒辦法有把握地回答

---

## 資料健檢做什麼

我用 Python 自動掃描你的資料，從四個面向找出問題：

| 檢查面向 | 找什麼 |
|---|---|
| 完整性 | 缺值、空白欄位、必填沒填 |
| 一致性 | 跨表格的 ID 對不起來、格式不一、分類不統一 |
| 準確性 | 金額異常、數量為負、日期邏輯錯誤 |
| 唯一性 | 重複的訂單、重複的客戶、重複的品項 |

## 交付內容

1. **自動化掃描腳本**：可重複執行，下次資料更新直接重跑
2. **健檢報告**（PDF 或 Markdown）：整體分數 + 問題清單 + 優先修復建議
3. **問題明細**（CSV）：每筆有問題的資料，含欄位名稱與錯誤原因
4. **說明文件**：如何解讀報告、如何跟 IT 或資料來源溝通

## Summary
An open-source implementation of a **BaZi (八字 - Four Pillars of Destiny)** server following the **Model Context Protocol (MCP)**. It allows AI models that support MCP (like Claude Desktop or Hermes with an MCP client) to perform BaZi calculations and traditional Chinese destiny analysis.

### Key Features
- **MCP Integration**: Seamlessly connects with AI agents to provide specialized domain knowledge.
- **Accurate Calculations**: Handles traditional calendar conversions and pillar derivations.
- **Open Source**: Part of the `openfate-ai` initiative.
